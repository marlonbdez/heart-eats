# Fichas de casos de uso

Una ficha corta por caso de uso (CU), por paquete. El catálogo, los actores y los diagramas están en [`../10_CASOS_DE_USO.md`](../10_CASOS_DE_USO.md).

| Paquete | CU | Ficha |
|---|---|---|
| Descubrir | CU-01 a CU-09 | [descubrir.md](descubrir.md) |
| Colaborar | CU-10 a CU-14 | [colaborar.md](colaborar.md) |
| Negocio | CU-15 a CU-17 | [negocio.md](negocio.md) |
| Moderación | CU-18 a CU-27, CU-33, CU-34 | [moderacion.md](moderacion.md) |
| Información | CU-28 a CU-32 | [informacion.md](informacion.md) |

Cada ficha tiene, como mucho: **Quién**, **Pasos**, **Si no** (lo que puede fallar), **Reglas** y, si las hay, **Observaciones** (huecos que el análisis ha hecho aflorar; no son decisiones). Los textos de interfaz van entre «comillas», tal como salen en español.
