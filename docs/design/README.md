## Cómo verlos

Son archivos `.dc.html` de un editor de lienzo de Claude: **no se abren directamente en el navegador**, necesitan su runtime. Sirven como fuente de verdad del diseño y para volver a subirlos a un lienzo nuevo. La versión visible fue un artifact privado de Marlon en claude.ai.
