# Contribuir a HeartEats

Proyecto en Fase 0: por ahora las contribuciones útiles son comentarios sobre las especificaciones en `docs/`.

- Ramas: `feat/…`, `fix/…`, `docs/…`. `main` protegida.
- Commits convencionales recomendados.
- Cada PR enlaza su issue y actualiza la documentación si cambia algo relevante.
- Documentación en español; código y variables en inglés.
